Verola Hotel Website

Verola Hotel is a hotel website designed to present the hotel and its services through an elegant and user-friendly layout.

Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Animations

- Organized page layout using Flexbox and Grid.
- Interactive hover effects.
- CSS animations.
- Responsive visual design elements.
